
> **Alkeny** - węglowodory nasycone, które w cząsteczce zawierają *jedno wiązanie* podwójne między *atomami węgla*
>  Nazwy **wszystkich alkenów** kończą się na *-en*


H \               / H
      C = C              (wszystkie wiązania kowalencyjne)
H /               \ H

Jest tylko jedno wiązanie podwójne pomiędzy węglami
### Wzór ogólny:
# $C_nH_{2n}$

1) **Metan** nie ma odpowiednika - Nie można zrobić wiązania podwójnego (bo nie ma 2 atomów węgla)

2) **Eten**
H \               / H
      C = C
H /               \ H

 $C_2H_4$
$CH_2 = CH_2$
$CH_2 CH_2$

3) **Propen**
H \           | H     / H
     C = C - C - H
H /                     \ H

$C_3H_6$
$CH_2 = CH - CH_3$
$CH_2CHCH_3$

4) **But-1-en** (te $1$ bo przy pierwszym atomie węgla jest wiązanie podwójne)
H \                   | H      / H
     C = C - C - C - H
H /       H |      | H      \ H

$C_4H_8$
$CH_2 = CH - CH_2 CH_3$
$CH_2CHCH_2CH_3$

5) **Pen-1-en**
H \                   | H  | H     / H
     C = C - C - C - C - H
H /       H |      | H   | H    \ H

$C_5H_{10}$
$CH_2 = CH - CH_2 - CH_2 CH_3$
$CH_2CHCH_2CH_2CH_3$

6) **Hex-1-en**
H \                   | H  | H  | H      / H
     C = C - C - C - C - C - H
H /       H |      | H   | H  | H    \ H

$C_6H_{12}$
$CH_2 = CH - CH_2 - CH_2 - CH_2 CH_3$
$CH_2CHCH_2CH_2CH_2CH_3$

7) **Hep-1-en**
H \                   | H  | H  | H  | H     / H
     C = C - C - C - C - C - C - H
H /       H |      | H   | H  | H  | H   \ H

$C_7H_{14}$
$CH_2 = CH - CH_2 - CH_2 -  CH_2 - CH_2 CH_3$
$CH_2CHCH_2CH_2CH_2CH_2CH_3$

8) **Okt-1-en**
H \                   | H  | H  | H  | H  | H   / H
     C = C - C - C - C - C - C - C - H
H /       H |      | H   | H  | H  | H  | H   \ H

$C_8H_{16}$
$CH_2 = CH - CH_2 - CH_2 - CH_2 - CH_2 - CH_2 CH_3$
$CH_2CHCH_2CH_2CH_2CH_2CH_2CH_3$

9) **Non-1-en**
H \                   | H  | H  | H  | H  | H  | H    / H
     C = C - C - C - C - C - C - C - C - H
H /       H |      | H   | H  | H  | H  | H  | H    \ H

$C_9H_{18}$
$CH_2 = CH - CH_2 - CH_2 - CH_2 - CH_2 - CH_2 - CH_2 CH_3$
$CH_2CHCH_2CH_2CH_2CH_2CH_2CH_2CH_3$

10) **Dek-1-en**
H \                   | H  | H  | H  | H  | H  | H  | H    / H
     C = C - C - C - C - C - C - C - C - C - H
H /       H |      | H   | H  | H  | H  | H  | H  | H    \ H

$C_{10}H_{20}$
$CH_2 = CH - CH_2 - CH_2 - CH_2 - CH_2 - CH_2 - CH_2 - CH_2 CH_3$
$CH_2CHCH_2CH_2CH_2CH_2CH_2CH_2CH_2CH_3$
