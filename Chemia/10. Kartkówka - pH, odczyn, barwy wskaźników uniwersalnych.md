
# pH

pH to jest miara kwasowości lub zasadowości roztworów wodnych

![[Pasted image 20261006101530.png|539]]

Skala pH jest od $0$ do $14$, ale musi zajść zależność:
**$pH + pOH = 14$**

| Typ odczynu |       Wzór       |        |
| :---------: | :--------------: | ------ |
|   Kwasowy   | $[H^+] > [OH^-]$ | pH < 7 |
|  Obojętny   | $[H^+] = [OH^-]$ | pH = 7 |
|  Zasadowy   | $[H^+] < [OH^-]$ | pH > 7 |

**Mamy różne wzory pozwalające na określenie pH:**
$[H^+] = 10^{-pH}$
$[OH^-] = 10^{-pOH}$

$[pH] = -\log[H^+]$
$[pOH] = -\log[OH^-]$
